# КОРА 35 — бюджет юбилейного проекта

Одностраничный обзор бюджета для передачи руководству. Статическая страница,
без скриптов и без бэкенда.

**Публичная версия:** https://kogandmitry.github.io/kora35-budget/

## Что здесь есть и чего нет

Страница показывает статьи расходов, суммы по блокам и сводку по лимиту.

Публичная редакция обезличена:

- исполнители названы ролями («Основной ведущий торжественной части»,
  «Координаторы блоков», «Йога-тренер»), персональные имена и фамилии убраны;
- `data/budget.json` сокращён до минимума, который нужен странице
  (`meta.ceiling` и `id` / `block` / `type` по строкам). Внутренние поля живой
  таблицы — суммы построчно, `sourceRef`, `basis`, состав участников,
  итоги по сценариям — в репозиторий не выгружаются;
- страница помечена `noindex, nofollow, noarchive`.

Оперативный источник истины — рабочий пульт проекта, не этот репозиторий.

Расходы на кулинарный мастер-класс учтены в строке «Мастер-классы (растения,
кулинария, ...)» — 15 000 ₽. Строка не закрыта: расходы продолжают поступать,
и при превышении плана сумму нужно поднять.

## Сборка

```bash
node scripts/build.mjs
```

Скрипт собирает `index.html` из `data/budget.json` и таблицы `current`
внутри самого скрипта. Правки вносятся в скрипт, затем сборка перезапускается —
`index.html` руками не редактируется.
